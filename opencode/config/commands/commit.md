Crea un commit git siguiendo estas instrucciones adicionales del usuario:

```text
$ARGUMENTS
```

Si el usuario indico ficheros, confirma solo esos ficheros. Si no indico ficheros, decide el conjunto minimo coherente de cambios para un unico commit.

El commit debe usar Conventional Commits y contener solo el subject en ingles, sin body ni footer.
